# Полные главы Библии для Telegraph

Бот публикует полные главы в Telegraph и отправляет обычную URL-кнопку «Прочитать всю главу». Публикация открывается в Telegram как статья Instant View. Отдельный frontend, Mini App и публичный HTTPS-адрес проекта для чтения не нужны.

## Где хранить тексты глав

Одна глава — один JSON-файл:

    backend/internal/bibletext/chapters/synodal/{book_id}/{chapter}.json

Например, Матфея 4:

    backend/internal/bibletext/chapters/synodal/40/4.json

ID книги соответствует традиционному порядку 66 книг Библии: Бытие — 1, Исход — 2, ..., Матфея — 40, Марка — 41, Луки — 42, Иоанна — 43, Откровение — 66.

## Формат JSON

    {
      "book": "Матфея",
      "chapter": 4,
      "translation": "Синодальный перевод",
      "verses": [
        { "number": 1, "text": "Полный текст первого стиха главы." },
        { "number": 2, "text": "Полный текст второго стиха главы." },
        { "number": 3, "text": "Полный текст третьего стиха главы." }
      ]
    }

Это пример структуры, а не текст Библии. В файл нужно внести **все стихи конкретной главы по порядку**, начиная с номера 1. Пропущенные номера, пустые стихи и несовпадающий номер главы не пройдут проверку. Текст главы должен укладываться в ограничение Telegraph API — 64 КБ содержимого.

Сейчас подключён Синодальный перевод. Если у вопроса указан другой перевод, бот не подменяет его Синодальным.

## Как работает публикация

1. При открытии вопроса бот берёт ссылки на стихи из поля BiblePassages.
2. Определяет книгу и главу, затем загружает соответствующий JSON-файл из backend.
3. Отправляет полный текст главы в Telegraph API методом createPage.
4. Добавляет под вопросом кнопку с обычной ссылкой на статью. Для разных глав добавляются отдельные кнопки.

Ссылки на созданные статьи кэшируются в памяти работающего backend: повторное открытие той же версии главы не создаёт новую публикацию в течение одного запуска. После перезапуска backend кэш очищается.

## Настройка Telegraph

1. Получите access token через официальный метод [Telegraph createAccount](https://api.telegra.ph/createAccount). Например:

       curl -X POST https://api.telegra.ph/createAccount -d "short_name=SlovoBible" -d "author_name=Слово"

2. Скопируйте значение result.access_token в корневой файл .env:

       TELEGRAPH_ACCESS_TOKEN=ваш_токен

3. После добавления файлов глав и настройки токена пересоберите backend:

       docker compose up --build -d backend

Токен Telegraph — секрет. Не добавляйте его в Git и не отправляйте в общие чаты.
