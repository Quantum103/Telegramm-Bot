# Главы Библии для Telegram Mini App

Полный текст Библии хранится в самом проекте. Внешние сайты для чтения глав не используются.

## Где хранить главы

Одна глава — один JSON-файл:

`web/public/bible/synodal/{book_id}/{chapter}.json`

Например, Матфея 4:

`web/public/bible/synodal/40/4.json`

Идентификаторы книг соответствуют традиционному порядку 66 книг Библии: Бытие — 1, Исход — 2, ..., Матфея — 40, Марка — 41, Луки — 42, Иоанна — 43, Откровение — 66.

## Формат файла

```json
{
  "book": "Матфея",
  "chapter": 4,
  "translation": "Синодальный перевод",
  "verses": [
    { "number": 1, "text": "Полный текст первого стиха главы." },
    { "number": 2, "text": "Полный текст второго стиха главы." }
  ]
}
```

В примере показаны только два стиха для демонстрации структуры. В рабочий файл нужно добавить все стихи главы — каждый со своим номером.

## Как работает подсветка

Ссылка Mini App формируется из существующих `BiblePassages` вопроса. Например, `Матфея 4:4-7` подсветит стихи 4, 5, 6 и 7. Несколько диапазонов одной главы объединяются; соседние диапазоны сливаются автоматически.

Mini App загружает JSON по номеру книги и главы, показывает всю главу и выделяет нужные стихи цветным фоном. Размер текста можно менять кнопками A− и A+.

## Добавление новой главы

1. Создай каталог с ID книги, если его ещё нет.
2. Создай JSON-файл с номером главы.
3. Впиши название книги, номер главы и полный массив стихов.
4. Пересобери и перезапусти frontend, чтобы файл попал в статические ресурсы.

Сейчас Mini App показывает Синодальный перевод. Для другого перевода нужно добавить отдельный набор файлов и явно сопоставить его с названием перевода в материалах вопроса.
