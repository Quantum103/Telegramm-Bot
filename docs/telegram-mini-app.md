# Telegram Mini App

Ученическое приложение открывается внутри Telegram и использует тот же каталог курсов, личный кабинет, прогресс и прохождение уроков, что и обычные команды бота. Основные вкладки приложения — **«Личный кабинет»** и **«Курсы»**.

## Настройка

1. Разверните проект на публичном домене с HTTPS. Telegram Mini Apps не должны открываться по локальному адресу `localhost`.
2. В локальном `.env` задайте уже используемый токен бота и публичный URL Mini App:

   ```dotenv
   TELEGRAM_BOT_TOKEN=токен_от_BotFather
   TELEGRAM_WEBAPP_URL=https://example.com/miniapp.html
   ```

   URL должен указывать на путь `/miniapp.html` того же frontend-домена, который проксирует запросы `/api/` к backend.
3. Кнопка запуска добавляется прямо в inline-клавиатуру сообщения `/start`; для такого `web_app`-кнопочного запуска отдельная настройка `/setdomain` не требуется. Адрес должен быть публичным HTTPS URL. При необходимости можно дополнительно настроить постоянную кнопку меню чата через [@BotFather](https://t.me/BotFather) командой `/setmenubutton`, указав тот же адрес.
4. Пересоберите и перезапустите приложение:

   ```bash
   docker compose up --build -d
   ```

5. Откройте личный чат с ботом и отправьте `/start`. В главном меню появится кнопка **«Открыть приложение»**. Старые кнопки и команды остаются доступными.

## Безопасность и данные

Frontend передаёт оригинальное поле `Telegram.WebApp.initData` в заголовке `X-Telegram-Init-Data`. Backend проверяет HMAC-подпись с использованием токена бота и ограничивает срок действия данных авторизации. Telegram ID берётся только из проверенной подписи, а не из параметров, которые можно изменить в браузере.

Mini App использует существующие `StudentService`, `CatalogService` и `LearningService`. Отдельная таблица учеников и миграция базы данных не нужны. Запросы на старт курса, открытие урока, сохранение ответа, навигацию по вопросам и завершение урока проходят через существующие проверки доступа и состояния обучения.

API Mini App находится в `/api/v1/miniapp/*`. Он предназначен для ученического приложения и не заменяет защищённые маршруты панели сотрудников.

## Локальная разработка

Обычный браузер на `http://localhost:8081/miniapp.html` покажет инструкцию открыть приложение из Telegram, поскольку в обычном браузере нет подписанного `initData`. Проверяйте авторизацию в Telegram-клиенте с настроенным публичным HTTPS-доменом. Не отключайте проверку подписи для локального тестирования и не используйте тестовый Telegram ID как замену авторизации.
